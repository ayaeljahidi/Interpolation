# Lagrange, Newton & Hermite Interpolation of eˣ

Numerical Analysis homework: three classical polynomial interpolation methods applied to
**f(x) = eˣ** at the nodes **x = −1, 0, 1, 2**, computed symbolically with SymPy,
compared graphically, and checked against the theoretical error bounds.

| Method   | Data used     | Degree | Max error on [−1, 2] |
|----------|---------------|:------:|:--------------------:|
| Lagrange | f(xᵢ)         |   3    | 9.47 × 10⁻²          |
| Newton   | f(xᵢ)         |   3    | 9.47 × 10⁻²          |
| Hermite  | f(xᵢ), f′(xᵢ) |   7    | 4.92 × 10⁻⁵          |

Key takeaways:

- **Lagrange and Newton give exactly the same polynomial** (uniqueness of the interpolating
  polynomial); they only differ in how it is written and computed.
- **Hermite** also matches the derivative at every node, giving a degree-7 polynomial that is
  about **2000× more accurate** on [−1, 2].

The full write-up (theory, hand computation, figures, error analysis) is in
[`report/report.pdf`](report/report.pdf).

## Usage

```bash
python interpolation.py            # prints results and saves the figures in ./figures/
python interpolation.py --show     # same, and also opens the plot windows
```

Without `--show` the script uses a non-interactive Matplotlib backend, so it also runs on
a server or in CI without a display.

## What the script does

1. **Setup**: defines f(x) = eˣ and the nodes `[-1, 0, 1, 2]`; f′ = eˣ is obtained by
   symbolic differentiation.
2. **Lagrange**: builds P(x) = Σ yᵢ Lᵢ(x) with the basis polynomials Lᵢ.
3. **Newton**: builds the divided-difference table and the Newton polynomial.
4. **Hermite**: builds the divided-difference table on the doubled nodes
   `z = [x₀, x₀, x₁, x₁, …]`, using f[xᵢ, xᵢ] = f′(xᵢ).
5. **Sanity checks**: verifies *exactly* (symbolically) that
   - P(xᵢ) = f(xᵢ) for all three methods,
   - P′(xᵢ) = f′(xᵢ) for Hermite,
   - Lagrange and Newton are the same polynomial,
   - the degrees are 3, 3 and 7.
6. **Plots & errors**: individual plots, a comparison plot, error plots (linear and log
   scale), maximum errors, and the theoretical bounds
   `e²/4!` (Lagrange/Newton) and `e²/8!` (Hermite).

## Changes compared with the first version

- **Hermite bug fixed.** The original mixed two indexing conventions for the
  divided-difference table (lower-triangular when filling column 1, upper-triangular
  afterwards). The resulting polynomial did not satisfy P(xᵢ) = f(xᵢ), and its maximum
  error was about **2.9** instead of **5 × 10⁻⁵**. The table now uses the same
  convention as the Newton table, `Q[i][j] = f[zᵢ, …, zᵢ₊ⱼ]`.
- `sp.simplify` replaced by `sp.expand`: `simplify` rewrote exponentials as `cosh`/`sinh`,
  which made exact comparisons fail and the output harder to read.
- Added exact **sanity checks** (see above).
- Maximum error is now reported **on the interpolation interval [−1, 2]** *and* on the
  wider plotting range, so extrapolation error does not hide the real accuracy.
- Added a **log-scale error plot** (the Hermite error is invisible on a linear scale) and the
  **theoretical error bounds**.
- Figures are **saved** to `figures/` (`plt.savefig`) instead of only shown, with an optional
  `--show` flag.
- Integer divisions wrapped in `sp.Integer(...)` to keep all coefficients exact.
